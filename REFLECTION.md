# Project Reflection

For this AI-assisted project, I adapted and improved the **Firefighter Safety Data Hub**, a full-stack application. I developed this application with the help of ChatGPT to work at production level. For this AI based project, I modified it with the help of Codex and ChatGPT so that it can be executed and operated locally in the user's machine. Initially, this application's backend was connected to AWS cloud but to make it accessible for the users, I made a local version of it.
The system includes a Flutter application for firefighter data entry, a FastAPI backend for authentication and data processing, a React researcher dashboard for viewing and exporting information, and a local SQLite database. Important features include user registration and verification, fire-event logging, PPE tracking, smoke-sampler data entry, location history, researcher access, and CSV export.

I used **ChatGPT and Codex as coding assistants throughout different stages of the work**.
ChatGPT helped me through structuring the entire project. It provided the code for API integration, authentication and helped me with several debugging problems. Examples included stale authentication tokens, account verification behavior, multi-row smoke-sampler submissions, location synchronization, and account deletion with related records. Codex was especially useful for reviewing the complete repository, identifying unnecessary or sensitive files, and refactoring the project into a simpler local development setup. I Used AI help with drafting logs and read me file. I did not treat the generated suggestions as automatically correct. I reviewed them and made changes wherever it was needed.

The most important that I learned from AI coding is that these tools are most useful when the proper context and requirements are given and once the result is generated, it is reviewed and then only that part is implemented which fits the requirement. However, there are problems as well. A suggested fix can solve one error while introducing a mismatch somewhere else, especially in a project with multiple frontends, authentication, and persistent data. Therefore, it is very necessary to check the workflows and complete functionality with all the user cases.

In this project, I would improve researcher analytics and visualization, strengthen role-based permissions. I would also continue simplifying the user experience so exposure information can be recorded quickly and consistently after an incident. I would even add a RAG system that can be used to quickly pickup the required data from the user incidents.
